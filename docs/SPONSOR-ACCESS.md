# Sponsor access to the full build

The public HeartIQ demo is intentionally complete and free to run. The production-shaped full build is kept in a separate private repository called `heartiq-full`.

## Why access is manual

The `omegaapi-india` GitHub account is a personal account, not an organization. GitHub Sponsors can grant private-repo rewards automatically only for organization sponsorships. Until an organization is configured, access is handled manually.

## Request steps

1. Sponsor OmegaAPI at https://github.com/sponsors/omegaapi-india.
2. Email info@omegaapi.com with the subject `HeartIQ full version access` and include your GitHub username.
3. Alternatively, send the same details to https://t.me/Omegaapiofficial.
4. Access is granted after the sponsorship is confirmed.

## What is in the private repo

- Real account signup and login with signed HttpOnly sessions
- D1 schema for profiles, likes, matches, reports, and moderation actions
- Mutual-consent match logic instead of simulated flags
- Report queue and admin moderation endpoints
- Retention, backups, and deployment runbook

There is no payment, card, checkout, or subscription code in the full build. Sponsorship is handled only on GitHub.
